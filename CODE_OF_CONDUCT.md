# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intentions, and keep discussions about
the work.

To report unacceptable behaviour, contact the maintainer,
[@bameda](https://github.com/bameda), privately. Reports are handled
confidentially.
