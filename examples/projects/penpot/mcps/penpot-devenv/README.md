# Penpot devenv (`penpot-devenv`)

A project-only MCP server: the Penpot MCP server that Penpot's development
environment runs on your machine, on port 4401, when started with
`./manage.sh run-devenv --agentic`.

It allows `host:4401`, that port of your machine and nothing else (see
[a port of your machine](../../../../../docs/network.md#a-port-of-your-machine)).
To use it, connect the Penpot plugin to the MCP server from the Penpot you
have open, as the devenv's documentation explains.
